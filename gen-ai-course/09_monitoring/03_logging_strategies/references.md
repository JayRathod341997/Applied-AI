- **Python `logging` — Logging Cookbook** — structured logging, filters, handlers, and JSON formatting patterns: https://docs.python.org/3/howto/logging-cookbook.html
- **structlog** — a popular library for structured, context-rich logging in Python: https://www.structlog.org/
- **Elastic Common Schema (ECS)** — a shared field naming convention so logs from different services stay queryable together: https://www.elastic.co/guide/en/ecs/current/index.html
- **OpenTelemetry — Traces** — spans, trace context propagation, and exporters; the vendor-neutral tracing standard: https://opentelemetry.io/docs/concepts/signals/traces/
- **OpenTelemetry Python** — instrumenting Python services for traces, metrics, and logs: https://opentelemetry.io/docs/languages/python/
- **Microsoft Presidio** — open-source PII detection and de-identification (analyzer + anonymizer): https://microsoft.github.io/presidio/
- **Python `re` — Regular Expressions** — reference for the regex used in PII redaction: https://docs.python.org/3/library/re.html
- **Python `hashlib`** — SHA-256 and friends for one-way hashing of identifiers: https://docs.python.org/3/library/hashlib.html
- **GDPR — Official Text** — data minimisation and the right to erasure that shape log retention: https://gdpr-info.eu/
- **Elastic — The ELK Stack** — Elasticsearch, Logstash/Beats, and Kibana for log aggregation and search: https://www.elastic.co/elastic-stack
- **Grafana Loki** — cost-effective, label-based log aggregation that pairs with Grafana: https://grafana.com/oss/loki/
