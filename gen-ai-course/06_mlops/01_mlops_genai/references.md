# References

- **Google Cloud — MLOps: Continuous delivery and automation pipelines in ML** — the canonical write-up of MLOps maturity levels (0/1/2) and the end-to-end ML lifecycle: https://cloud.google.com/architecture/mlops-continuous-delivery-and-automation-pipelines-in-machine-learning
- **Hidden Technical Debt in Machine Learning Systems (Sculley et al., NeurIPS 2015)** — the classic paper showing ML code is a small part of a real ML system; the origin of much MLOps thinking: https://papers.nips.cc/paper/2015/hash/86df7dcfd896fcaf2674f757a2463eba-Abstract.html
- **Microsoft — MLOps & GenAIOps reference architectures (Azure Machine Learning)** — enterprise reference architectures for operationalizing ML and GenAI: https://learn.microsoft.com/en-us/azure/machine-learning/concept-model-management-and-deployment
- **MLflow Documentation** — open-source platform for experiment tracking, model registry, and stage promotion (None/Staging/Production): https://mlflow.org/docs/latest/index.html
- **MLflow Model Registry** — registering models, versioning, and transitioning stages — the production analogue of the exercise registry: https://mlflow.org/docs/latest/model-registry.html
- **AWS Well-Architected Framework — Machine Learning Lens** — design principles for reliable, scalable, cost-aware ML/AI workloads: https://docs.aws.amazon.com/wellarchitected/latest/machine-learning-lens/machine-learning-lens.html
- **AWS SageMaker MLOps** — managed end-to-end ML lifecycle: pipelines, model registry, and deployment: https://aws.amazon.com/sagemaker/mlops/
- **Google Vertex AI** — GCP's managed MLOps platform (pipelines, model registry, monitoring): https://cloud.google.com/vertex-ai/docs
- **Made With ML — MLOps Course (Goku Mohandas)** — a thorough, practical open course covering the full MLOps lifecycle: https://madewithml.com/
- **ml-ops.org — MLOps Principles** — vendor-neutral overview of MLOps principles, components, and maturity: https://ml-ops.org/content/mlops-principles
- **Chip Huyen — "Designing Machine Learning Systems" (book site)** — system design for production ML, including data, deployment, and monitoring: https://huyenchip.com/machine-learning-systems-design/
